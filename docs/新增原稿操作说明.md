# 新增原稿操作说明（怎么把爆款稿加进原稿库）

## 方式一：网页内直接加（推荐，30 秒搞定）

1. 双击打开「电商爆款脚本生成智能体-一键出稿版.html」
2. 点页面左下角「原稿库管理」，展开面板
3. 把你要入库的爆款口播稿**整段粘贴**进文本框
4. 选分类：痛点直击型 / 效果反差型 / 真实场景型
5. 点「加入原稿库」→ 立即生效，下一次生成就会用到它
6. 想备份：点「导出我的原稿」存成 JSON 文件；换电脑后点「导入」即可恢复

> 小提示：网页里加的稿子保存在当前浏览器（localStorage）。换浏览器或清缓存前，记得先导出备份。

## 方式二：直接改数据文件（可选，适合一次加很多篇）

1. 打开 data/original_scripts/ 目录
2. 选对应分类文件：pain.json（痛点直击型）/ 
everse.json（效果反差型）/ scenario.json（真实场景型）
3. 在 originals 数组里**复制一篇现有稿件**，按同样格式改成你的内容，每篇含 5 段：
   - hook 开头钩子 / pain 痛点场景 / product 产品卖点 / 	rust 信任背书 / cta 结尾引导
4. 保存后直接使用「电商爆款脚本生成智能体-一键出稿版.html」（网页版已内置原稿库）

> 日常用方式一就够了，两种方式加进去的稿子都会参与改写。
