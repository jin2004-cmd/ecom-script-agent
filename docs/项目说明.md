# 电商短视频爆款脚本生成智能体

**一句话定位**：面向千川/二类电商带货场景的爆款脚本生成智能体，内置真实爆款原稿库，选模板、点按钮一键出稿，框架 100% 保留、细节微调改写，输出自动过医疗品类合规校验，批量产出不撞款。

---

## 1. 项目背景与要解决的问题

千川带货短视频是二类电商的核心投放素材，但团队普遍面临三个问题：

1. **产量瓶颈**：爆款脚本依赖个人经验，新人产出的脚本结构松散、转化率低；
2. **质量不稳**：钩子、痛点、卖点、信任、CTA 五段结构常常缺环；
3. **合规风险**：功效类商品（尤其医疗相关品类）极易触碰广告法红线，轻则限流，重则违规处罚。

本项目用一个智能体把「爆款脚本方法论 + 真实原稿库 + 合规规则」沉淀成**开箱即用的网页智能体**：不写代码、不配环境，双击即用，贴合二类电商同品类批量出稿的真实工作场景。

## 2. 核心能力

| 能力 | 说明 |
| --- | --- |
| 网页版一键出稿 | 单 HTML 文件，双击打开即用：选模板 → 点「生成 1 条 / 批量 3 条」→ 直接出稿 |
| 真实爆款原稿库 | 内置 19 篇真实爆款原稿（痛点直击 6 / 效果反差 6 / 真实场景 7），分五段模块管理，可在网页内随时添加自己的稿子 |
| 爆款微改引擎 | 模块重组 + 同义替换 + 语序/语气微调，框架 100% 保留、细节不重复（与原稿及历史稿重复率 ≤60%） |
| 合规自动化 | 出稿自动替换违禁词、追加医疗合规提示语，输出即合规 |
| 命令行模式（进阶） | 模板模式零依赖、可复现（seed 控制）；LLM 模式可对接火山方舟/豆包；支持 Markdown/JSON/CSV/HTML 多格式导出 |
| 工程化 | 27 个单元测试全部通过；原稿库、模板库、合规规则全部外置 JSON，加稿无需改代码 |

## 3. 技术实现

- **主交付**：单 HTML 网页文件（电商爆款脚本生成智能体-一键出稿版.html），纯前端零依赖，双击即用
- **改写引擎**：五段模块（钩子/痛点/卖点/背书/CTA）随机组合 + 轻量改写，4-gram 覆盖率去重校验
- **合规引擎**：广告法绝对化用语检测 + 医疗品类功效夸大强校验 + 自动替换 + 合规提示语附加
- **命令行模式**：Python 3.9+，模板模式零第三方依赖，LLM 模式仅需 requests
- **数据驱动**：原稿库、模板库与合规规则全部外置为 JSON，新增品类/话术无需改代码

作为**业务规则设计者 + 产品设计者**：定义 3 类爆款模板的判定标准、五段脚本结构规范、医疗品类合规红线与自动修正规则、批量出稿的去重标准；并把这些业务规则落地成开箱即用的可视化智能体。

## 5. 示例成果（已实际运行产出）

- 网页版：三类模板各生成 20 条实测，100% 合规通过、100% 含产品名与合规提示语，与原稿重复率最高 57%（阈值 60%）
- 命令行版：医疗保健类 草本温灸肠胃贴（自动附带合规提示语，0 合规问题）、3C 数码类 主动降噪蓝牙耳机
